OldSkool Demoscene

This is a collection of my old demoscene projects from the 90s. It includes a variety of effects and applications written in Assembly, C, and Pascal for MS-DOS. You'll find things like BBS intros, 2D effects (water, fire, plasma), a 3D engine with 3D Studio support, and even a graphical disk copier inspired by the Amiga's X-Copy.

The code is a snapshot of the demoscene and hacking mentality of the time – not always clean, but functional and creative. It's a trip down memory lane with techniques like self-modifying code and anti-debugging tricks.

You can run most of these demos in DOSBOX.
